- `scripts/validate-content.mjs`：全動画の参照・原題・投稿者・時間根拠・原順序・目次・再生リスト・算術を検査。
- `.github/workflows/pages.yml`：公開前にコンテンツと主要回帰検査を実行。
- 学習記録のストレージ、動画ID、再生コンポーネント、同期、ピンクの既存デザイン、PWAの更新方式は維持。
